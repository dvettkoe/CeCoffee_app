# CeCoffee App

![](/script/logo.png)

## Overview

The CeCoffee App is an Android application designed to track coffee consumption in an office environment, effectively replacing traditional paper tally sheets. 

The application monitors individual coffee intake, features an office-wide leaderboard, and provides monthly consumption analytics for each user. To streamline the reimbursement process, the app generates a personalized QR code at the end of each month, allowing users to transfer their outstanding balance directly to the designated office fund manager.

---

## Getting Started

### Installation
Download the [latest release](https://github.com/dvettkoe/CeCoffee_app/releases/tag/v1.5.0) and install the application on a dedicated Android device stationed near your office coffee machine.

## Application Guide

### User Profiles
CeCoffee supports individual user profiles, which can be configured within the settings menu. Users can easily log a beverage by tapping their profile name. Upon logging a coffee, the application displays a brief, metaphysical quote to the user.

### Billing and Payments
At the conclusion of each month, the application automatically calculates each user's total balance based on a preconfigured price per cup. It then generates a customized PayPal QR code, enabling a seamless and direct transfer to the designated collection account.

To ensure timely payments, the application issues automated reminder notifications early in the following month.

### Analytics and Tracking
Users can view an office-wide leaderboard ranking total consumption, as well as personalized line graphs to visualize their individual monthly coffee trends.

### Administration and Settings
The settings module provides comprehensive control over the application's configuration:
* **User Management:** Add new user profiles or remove inactive ones as needed.
* **System Configuration:** Authorized administrators can log in to update global parameters, including the designated price per cup and the linked PayPal account used for generating payment QR codes.
